# Ashot

Небольшой проект для генерации рекламного вертикального видео (формат **3:4**) с помощью `ffmpeg`.

Скрипт `make_video.sh` собирает ролик из однотонного фона и набора текстовых/графических слоёв (`drawbox`, `drawtext`). По умолчанию он создаёт промо-видео для `CHANCE EAU FRAICHE`, но основные параметры можно менять при запуске.

Готовый файл по умолчанию сохраняется в папку `output` под именем:

`output/chance_eau_fraiche_3x4.mpeg4`

## Зависимости

Для запуска нужен:

- **bash** (скрипт использует `set -euo pipefail`);
- **ffmpeg** с поддержкой фильтров `drawtext` и `drawbox`;
- шрифты DejaVu, доступные по путям:
  - `/usr/share/fonts/truetype/dejavu/DejaVuSerif-Bold.ttf`
  - `/usr/share/fonts/truetype/dejavu/DejaVuSerif.ttf`
  - `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf`

Скрипт сам проверяет наличие `ffmpeg` и нужных шрифтов. Если шрифты лежат в другом месте, можно передать пути через переменные окружения:

```bash
FONT_SERIF_BOLD=/path/to/bold.ttf \
FONT_SERIF=/path/to/serif.ttf \
FONT_SANS=/path/to/sans.ttf \
./make_video.sh
```

## Как запустить

1. Выдать права на выполнение (один раз):

   ```bash
   chmod +x make_video.sh
   ```

2. Запустить генерацию видео с настройками по умолчанию:

   ```bash
   ./make_video.sh
   ```

3. После выполнения скрипт выведет путь к созданному файлу.

## Параметры

Скрипт поддерживает такие параметры:

- `--title TEXT` — основной заголовок. По умолчанию: `CHANCE EAU FRAICHE`.
- `--subtitle TEXT` — подзаголовок. По умолчанию: `ЖЕНСКИЕ ДУХИ`.
- `--duration SECS` — длительность видео в секундах. По умолчанию: `15`.
- `--out PATH` — путь к выходному файлу. По умолчанию: `output/chance_eau_fraiche_3x4.mpeg4`.
- `-h`, `--help` — показать справку.

Пример с другими текстами и длительностью:

```bash
./make_video.sh \
  --title "CHANCE" \
  --subtitle "ПРОМО 10ML" \
  --duration 8 \
  --out output/promo.mp4
```

## Проверки и ошибки

Перед запуском генерации скрипт проверяет:

- установлен ли `ffmpeg`;
- указана ли корректная длительность;
- существуют ли нужные файлы шрифтов;
- можно ли создать папку для результата.

Если что-то не так, он выводит понятную ошибку и завершает работу без создания видео.
